# Feature 1 Overview

## AI-Based Competency Assessment and Personalized Learning

Feature 1 evaluates an official's current competency, identifies competency
gaps, and recommends personalized learning resources from iGOT Karmayogi
and NSSTA/TPAC training programmes.

## Objective

The main objectives of Feature 1 are:

- Assess the current competency of an official
- Identify competency gaps
- Compare current competency with required competency
- Prioritize skill gaps
- Recommend relevant iGOT Karmayogi courses/modules
- Recommend NSSTA/TPAC training programmes
- Create a personalized learning path
- Track training progress
- Perform reassessment
- Measure competency improvement

## Main Components

### 1. Official Profile

Contains information about the official such as:

- Role
- Designation
- Job activities
- Experience
- Training history

### 2. Role & Competency Engine

Maps the official's role to the required competencies and competency levels.

### 3. AI Competency Assessment

Uses assessment questions generated by Feature 2 to evaluate the official's
current competency.

The assessment can include:

- MCQs
- Scenario-based questions
- Different difficulty levels
- Adaptive questions

### 4. Competency Scoring

Evaluates answers and calculates competency-wise scores.

### 5. AI Skill-Gap Analysis

Compares:

Required Competency vs Current Competency

and identifies:

- Skill gaps
- Gap severity
- Priority

### 6. Recommendation Engine

Finds learning resources that match the identified competency gaps.

### 7. iGOT Karmayogi

Provides relevant courses and learning modules.

### 8. NSSTA / TPAC

Provides relevant recommended training programmes.

### 9. Personalized Learning Path

Creates a learning sequence based on the official's competency gaps and
priorities.

### 10. Training Progress

Tracks course completion, training progress, and assessment results.

### 11. Re-assessment

Assesses the official again after completing the recommended training.

### 12. Competency Improvement

Compares competency before and after training and updates the competency
profile.

## Feature 1 and Feature 2 Integration

Feature 2 generates competency-tagged MCQs from uploaded learning material.

Feature 1 uses these questions and the official's answers to calculate
competency levels and identify skill gaps.

### Integration Flow

Feature 2
→ Assessment Questions
→ Official Answers
→ Competency Scoring
→ Skill-Gap Analysis
→ Learning Recommendations
→ Re-assessment
→ Competency Improvement
